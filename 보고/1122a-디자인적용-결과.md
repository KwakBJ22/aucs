## 확인한 것 / 못 한 것
- prettier 3.5.3: 고친 파일 모두 맞춤.
- tsc: 이 VM 은 react 형식을 못 찾아(늘 그런 것) TS2503(React) · key 류를 빼고 보면 고친 파일에서 새 오류 없음. 찾기 칩의 경매·공매 고르기 형식 하나는 미리 고침.
- 목숨줄 검사: 로그인 길이 「이메일로 계속하기」를 먼저 누르게 고침(`check/lifeline.mjs`). 이 VM 에서 화면을 띄울 수 없어 **검사 · 화면 눈 확인은 못 함** — 배포 배치가 검사를 돌림. 배포 뒤 PC 1280 폭으로 홈 · 찾기 · 상세(아파트 · 빌라 · 상가 · 땅) · 입찰표를 열어 볼 것.
- 머리 종 빨간 점: 서버를 따로 부르지 않고 홈 · 알림함에서 받은 목록으로 셈 — 그 두 화면을 한 번 연 뒤부터 보임.
- 확인 칸(체크박스) 회색 네모 모양은 안 바꿈(브라우저 기본 그대로).
