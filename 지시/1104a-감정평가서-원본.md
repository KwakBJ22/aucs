# 1104a 감정평가서 원본 — 대표님 PC에서 한 번만 (3분)

11/4 대표님: KAPA 사용 허락 · 법원에서 원본 받아 모두 활용.
감정서 번호는 법원 요청 하나로 받게 했고(court_docs), 원본은 새 수집기 `kapa_pdf` 가 받습니다(아침 묶음 「감정평가서 원본」, 하루 300건).
KAPA 쪽이 원본을 어떻게 내주는지(바로 PDF · 페이지 안 주소 · 내려받기)는 클라우드에서 확인이 안 돼, 세 길을 다 해 보게 짰습니다.

## 할 일
배포 뒤(또는 GitHub 받은 뒤) PC 에서:
```
cd D:\Auction\auction-platform\workers
uv run python -m aucs_workers.collectors.court_docs --case B000210 2022타경101244
uv run python -m aucs_workers.collectors.kapa_pdf --probe
```
- 첫 줄: 감정서 번호 받기(사건 하나).
- 둘째 줄: 원본 한 건 받아 보기. 「회사 이름 · ○쪽」이 나오면 끝 — 내일 아침부터 저절로 돕니다.
- 「원본 못 받음」이 나오면 `logs\kapa_probe.txt` 내용을 붙여 주세요(쿠키 같은 비밀은 들어 있지 않음).
